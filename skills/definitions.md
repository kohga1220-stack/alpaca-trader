## 1. テクニカル指標の定義

### RSI (14日)
| 値 | 解釈 |
|----|------|
| < 30 | 売られすぎ（反発候補）|
| 30–45 | やや売られすぎ |
| 45–55 | 中立 |
| 55–70 | やや買われすぎ |
| > 70 | 買われすぎ（調整候補）|

- RSI単独でBUY/SELLを決めない。トレンドと組み合わせて判断する。
- RSI < 30 かつ MA20 > MA50 のとき強い反発シグナル。
- RSI > 70 かつ MA20 < MA50 のとき強い反落シグナル。

### 移動平均（MA20 / MA50）
| 状態 | 解釈 |
|------|------|
| 現在価格 > MA20 > MA50 | 上昇トレンド（BUY優位）|
| MA20 が MA50 を上抜け（ゴールデンクロス）| 強い買いシグナル |
| 現在価格 < MA20 < MA50 | 下降トレンド（SELL優位）|
| MA20 が MA50 を下抜け（デッドクロス）| 強い売りシグナル |
| MA20 ≈ MA50（差 < 0.5%）| トレンドなし、HOLD優先 |

### 直近5日のトレンド判定
- 終値が5日連続上昇：強い短期上昇モメンタム
- 終値が5日連続下降：強い短期下降モメンタム
- 出来高が直近平均の1.5倍超かつ価格上昇：ブレイクアウト候補

## 2. ファンダメンタルズ指標の定義

### PER（株価収益率）
- 業種別に解釈が異なるため、HIGH_RISK / LOW_RISK で基準を分ける（各ファイル参照）
- PER が負（赤字）のときは成長性・キャッシュフローで代替評価する

### EPS（1株当たり利益）
- 前期比プラス成長：プラス材料
- 前期比マイナス：マイナス材料（ただし一時要因は考慮）

### 純利益率
| 値 | 評価 |
|----|------|
| > 20% | 優良 |
| 10–20% | 良好 |
| 5–10% | 普通 |
| < 5% | 要注意（業種による）|

### ROE（自己資本利益率）
| 値 | 評価 |
|----|------|
| > 20% | 優良 |
| 10–20% | 良好 |
| < 10% | 低い |

## 3. 売買判断の総合ルール

### BUY条件（以下を**複数**満たすこと）
1. 上昇トレンド（価格 > MA20 > MA50）
2. RSI < 65（買われすぎでない）
3. 確信度 ≥ 75
4. ファンダメンタルズが悪化していない

### BUY例外条件：逆張り反発シグナル（以下を**すべて**満たす場合、トレンド条件を免除）
- RSI < 30（極度の売られすぎ）
- 純利益率 > 15% かつ ROE > 20%（ファンダメンタルズ優良）
- MA50 がサポートとして機能している（価格 ≥ MA50 × 0.97）
- この条件を満たす場合、確信度 75 以上を付与してBUYを許容する

### SELL条件（以下を**複数**満たすこと）
1. 下降トレンド（価格 < MA20 < MA50）
2. RSI > 40（売られすぎでない）
3. 確信度 ≥ 75
4. 保有ポジションが存在する

### HOLD優先ケース
- シグナルが混在（テクニカルとファンダメンタルズが矛盾）
- RSI が 45–55 の中立域
- MA20 ≈ MA50（差 < 0.5%）
- 確信度 < 75

### ストップロス・テイクプロフィット（参考値）
- SL: エントリー価格から -6%
- TP: エントリー価格から +12%
- これらはシステム側で管理するため、判断には含めない

## 4. ポジションサイジング

- リスク/トレード: 総資産の 2%
- 推奨株数 = (総資産 × 0.02) / (現在価格 × 0.06)  ← SL 6% 想定
- 小数点は切り捨て、最低 1 株
- 現金残高が推奨株数 × 現在価格を下回る場合は現金に合わせて削減

## 5. 確信度（confidence）の定義

| スコア | 意味 |
|--------|------|
| 90–100 | 複数の強いシグナルが一致、ファンダ良好 |
| 75–89 | 主要シグナルが一致、多少の不確実性あり |
| 60–74 | シグナル混在、HOLDが妥当 |
| < 60 | 根拠不十分、必ずHOLD |

**確信度 < 75 のときは action を必ず "HOLD" にすること。**

### 確信度の加点ルール（各条件で加算）

| 条件 | 加点 |
|------|------|
| 上昇トレンド（価格 > MA20 > MA50） | +20 |
| RSI < 30（極度の売られすぎ、逆張り） | +20 |
| RSI 30–45（売られすぎ圏） | +10 |
| RSI 45–65（中立〜健全） | +5 |
| ゴールデンクロス発生中 | +15 |
| 純利益率 > 20% かつ ROE > 20% | +20 |
| 純利益率 10–20% または ROE 10–20% | +10 |
| MA50 がサポートとして機能（価格 ≥ MA50 × 0.97） | +10 |
| 直近5日で3日以上上昇 | +5 |

**加点の使い方：** 基準点50からスタートし、各条件の加点を足した合計が75以上になれば BUY/SELL を許容する。
例：上昇トレンド(+20) + ファンダ優良(+20) = 50+40 = 90 → BUY許容
例：RSI<30(+20) + ファンダ優良(+20) + MA50サポート(+10) = 50+50 = 100 → BUY許容

**【上限制約】RSI > 70 かつ下降トレンド（価格 < MA20 < MA50 またはデッドクロス）が重なる場合は、
加点合計に関わらず BUY の確信度は 60 を上限とする（高値掴み防止）。**
